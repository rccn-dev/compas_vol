********************************************************************************
compas_vol
********************************************************************************

Volumetric modelling with signed distance functions, for **COMPAS 2**.

This is a fork of `dbt-ethz/compas_vol <https://github.com/dbt-ethz/compas_vol>`_,
originally written by Mathias Bernhard at Digital Building Technologies, ETH
Zurich. It updates the package to COMPAS 2, NumPy 2 and Python 3.13, and fixes a
number of defects carried by the original. See :doc:`porting` for the details.

compas_vol.nodes

The Grasshopper components, without Grasshopper.

Every component in compas_vol/ghpython/components/ is a thin wrapper of one function here: Cv_Box calls box(), Cv_Boolean calls boolean(), and so on. Each function takes the component’s inputs by the same names, with the same defaults, and returns its outputs in the same order – but in COMPAS and NumPy types instead of Rhino ones. The component only converts on the way in and out (compas_vol.ghpython).

That has two uses. A definition worked out on the canvas can be rewritten as a plain script, node for node, and run headless: no canvas, no Rhino geometry in between, sampling on every core, and the final model written with compas_vol.meshing.export_stl() at a resolution Grasshopper could not draw. And everything a component does can be tested here, where pytest runs, rather than only inside Rhino. tests/test_ghpython.py checks that every node’s signature still matches its component.

Inputs follow Grasshopper’s conventions, because that is where they are wired up: an input left unconnected arrives as None and falls back to its default, and a node whose required input is missing returns None rather than raising, the way an unwired component stays empty.

The same model as a canvas of five components:

>>> from compas.geometry import Point
>>> from compas_vol import nodes
>>> ball = nodes.sphere(Point(0, 0, 0), 12.0)
>>> cube = nodes.box(None, 18.0, None, None, 2.0)
>>> body = nodes.boolean([cube, ball], "intersection", 1.0)
>>> body = nodes.boolean([body, nodes.tpms("Gyroid", 6.0, 1.2, None, None)], "intersection", 0)
>>> vertices, faces = nodes.mesh(body, (-10, -10, -10, 10, 10, 10), 48, 0)

sphere

A sphere as a signed distance field.

box

A box as a signed distance field, with optionally rounded edges.

cylinder

A cylinder as a signed distance field.

tpms

A triply periodic minimal surface, thickened into a printable solid.

boolean

Combine volumetric objects, optionally with a smooth blend at the seam.

shell

Hollow a volumetric object out into a shell of even thickness.

abrasion

Weathering that rounds: what sticks out wears first.

differential

Weathering by hardness: soft rock retreats, hard rock stands proud.

pitting

Weathering into hollows that deepen themselves: tafoni, honeycombing.

strata

Bedding: hard and soft layers weathering into ledges and overhangs.

runoff

Rain: water gathers downhill over the top of the model and cuts gullies.

jointing

Joints: the mass breaks into blocks, the seams opening from outside in.

fingering

Growth that folds into lobes and valleys: the brain-coral mechanism.

accretion

Growth that fills hollows: deposition settling where it is sheltered.

branching

A branching network grown by space colonization, drawn as a solid.

spinodal

A bicontinuous foam by phase separation: an aperiodic TPMS.

reactiondiffusion

Gray-Scott reaction-diffusion, set solid: spots, worms and labyrinths.

morphology

Enforce a minimum feature size: remove what is too thin, or fill what is too narrow.

mesh

Sample a volumetric object over a box and extract its surface.

inspect

Check a volumetric object for the things that stop a model printing.

info

Report what compas_vol can do here, and what is missing.

The process nodes – erosion, growth, phase separation – are simulations on a sampled grid rather than expressions, and each returns its result as a compas_vol.primitives.VolGrid, so it combines, shells and meshes like anything else. Handed a grid with no bounds, a process runs on that grid as it is, which is how processes chain without resampling; and the mesh and inspect nodes, handed a grid with no bounds, read the domain off it:

>>> body = nodes.box(None, 60.0, None, None, 0)
>>> worn, history = nodes.abrasion(body, 45.0, 32, 3.0, None, None)
>>> pitted, history = nodes.pitting(worn, None, None, 4.0, None, None, None, None, 0)
>>> vertices, faces = nodes.mesh(pitted, None, None, 0)

VolObjectSceneObject

class compas_vol.scene.VolObjectSceneObject(*args: Any, **kwargs: Any)[source]

Bases: MeshObject

Scene object for displaying a volumetric object in the COMPAS viewer.

A volumetric object is an implicit function, so it has to be sampled and iso-surfaced before it can be drawn. That is the same situation a compas.geometry.Shape is in – a sphere has to be tessellated before it has any vertices – and it is handled the same way: the sampling parameters ride along on the scene.add call, exactly as u and v do for compas_viewer.scene.ShapeObject.

Unlike u/v there is no sensible default for bounds. A compas_vol.microstructures.TPMS or compas_vol.microstructures.Lattice is infinite, and a compas_vol.combinations.Intersection cannot report an extent either, so the caller has to say where to look.

Parameters:

  • bounds (compas.geometry.Box | float | sequence) – The sampling domain. See compas_vol.meshing.normalize_bounds(). Required.

  • resolution (int | tuple[int, int, int], optional) – The number of samples along each axis. Default is 64.

  • level (float, optional) – The iso-value to extract. Default is 0.0, the object’s surface.

  • **kwargs – Passed on to compas_viewer.scene.MeshObject.

item

The volumetric object being displayed.

Type:

compas_vol.base.VolObject

mesh

The iso-surface of item, generated on first access.

Type:

compas.datastructures.Mesh

Examples

>>> from compas.geometry import Box, Point, Sphere
>>> from compas_vol.primitives import VolBox, VolSphere
>>> from compas_vol.combinations import Subtraction
>>> from compas_viewer import Viewer
>>> shape = Subtraction(VolBox(Box(20, 15, 10), 2.5), VolSphere(Sphere(9)))
>>> viewer = Viewer()
>>> viewer.scene.add(shape, bounds=20.0, resolution=100)
>>> viewer.show()

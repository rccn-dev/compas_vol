abrasion

compas_vol.nodes.abrasion(vol, bounds, resolution, depth, length, edge_bias, run=None)[source]

Weathering that rounds: what sticks out wears first.

Parameters:

  • vol (compas_vol.base.VolObject) – The starting solid. A compas_vol.primitives.VolGrid with no bounds runs on its own grid.

  • bounds (float | sequence, optional) – The box to sample vol over. Leave room: the surface only retreats here, but anything touching the edge is cut there.

  • resolution (int, optional) – Samples per axis. Defaults to 64. It sets the finest feature any process can make: below about two voxels, nothing survives.

  • depth (float, optional) – Millimetres removed from a flat face. Defaults to 4.

  • length (float, optional) – Feature size curvature is measured against, roughly the radius the sharpest edge ends up with. Defaults to 9.

  • edge_bias (float, optional) – How much faster an edge wears than a face. Defaults to 2.

  • run (bool, optional) – False skips the work and returns (None, None). On the canvas the component holds its last result instead, so a slow process can be paused while things upstream change; unwired, it runs.

Returns:

tuple[compas_vol.primitives.VolGrid, str] | tuple[None, None] – The worn solid, and how it was made.

See also

compas_vol.processes.abrasion()

Examples

>>> worn, history = abrasion(box(None, 20.0, None, None, 0), 14.0, 24, 1.0, None, 0)
>>> round(worn.get_distance([10, 0, 0]), 1)   # a flat face, 1 mm back
1.0
>>> history.splitlines()[-1].split("(")[0]
'abrasion'

Examples

All examples live in the examples/ directory of the repository and are runnable as-is:

$ uv sync --extra examples

Single operations

examples/*.py are short ports of the original scripts, one idea each — extrusion, the four booleans, smooth booleans, morph, lattice, TPMS, Voronoi, gradient and octree:

$ uv run --extra all python examples/example_tpms.py

Modelling studies

examples/vol_mesh_examples/ holds fuller studies. Each opens the viewer with the meshed result; closing it opens an interactive slice through the signed distance field, where a slider moves the cutting plane — blue is inside, red is outside, and the black contour is the surface that gets meshed:

$ uv run python examples/vol_mesh_examples/8_morphing_microstructure.py

The first six are ordinary constructive modelling. The last six are the ones worth reading if you already know CSG: none of them is a boolean of two finished shapes, and each varies a property continuously through space rather than tiling one unit cell.

Grasshopper

The components sit under a COMPAS Vol tab. Each is a thin wrapper of one function in compas_vol.nodes, with the same inputs in the same order.

Installing

Rhino 8 has its own Python 3.9, so a terminal install does not reach it: install the package into Rhino’s Python, then the components.

  1. From a clone of this repository, install it into Rhino’s Python:

    # macOS
~/.rhinocode/py39-rh8/python3.9 -m pip install -e "./compas_vol[meshing,processes]"

    # Windows (PowerShell)
& "$env:USERPROFILE\.rhinocode\py39-rh8\python.exe" -m pip install -e ".\compas_vol[meshing,processes]"

    scikit-fmm, which the processes need, compiles from source on macOS and needs the Xcode command line tools; Windows gets a wheel.

  2. Download compas_vol-ghuser.zip from the releases and unzip it into Grasshopper’s User Object folder (File › Special Folders › User Object Folder).

  3. Restart Rhino. Volumetric Info lists what is installed.

To work on compas_vol itself, scripts/ghuser dev builds the components and links them into Grasshopper, importing the package from src/ (see Development).

Each takes bounds and resolution like Volumetric Mesh, and returns a VolGrid plus its history.

  • To chain processes, leave bounds unwired downstream: the component then runs on the incoming grid, without resampling. Mesh and Inspect read the box off a grid the same way. Branching, Spinodal and Reaction Diffusion need a box.

  • Use run. Each process takes 1-5 s at resolution 64 and reruns on every input change. Set run to False with a Boolean Toggle to hold the last result while adjusting upstream; unwired, it runs.

From canvas to script

A definition can be rewritten node for node and run headless, at resolutions Grasshopper could not draw:

from compas_vol import nodes
from compas_vol.meshing import write_stl

body = nodes.boolean([nodes.box(None, 40.0, None, None, 4.0), nodes.sphere(None, 26.0)], "intersection", 2.0)
body = nodes.boolean([body, nodes.tpms("Gyroid", 8.0, 1.2, None, None)], "intersection", 0)
vertices, faces = nodes.mesh(body, 22.0, 400, 0)
write_stl("part.stl", vertices, faces)
